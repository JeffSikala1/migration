I dug into this and want to flag before we change anything: the latestVersion lookup exists to feed the post-deploy Bamboo Deploy injector task used by WS and Reconciliation, but ENV does not have that injector task or a downstream Bamboo Deploy plan because env-base, build-tools, and env are BOM/POM artifacts, not deployable apps. DISC ENV used the equivalent deploy-to-artifactory-skip-bamboo-version.sh script and also did not perform a latestVersion lookup, so adding it to ENV would only run an Artifactory query whose result no task reads.
