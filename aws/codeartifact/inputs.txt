/cache/bamboo/ isn't just a build cache — it's what makes our integration tests work. When Maven spins up the postgres/jboss containers for integration testing, it does it via the host's Docker daemon (not nested inside the agent), so any files our build unpacks under target/ (pg-datafile, billingsftp volume data, etc.) only show up correctly in those sibling containers if the agent's build directory is bind-mounted at the identical path on the host. That's why both /var/run/docker.sock and /cache/bamboo/<agent-name> need to be mounted into every agent — dropping either one breaks integration tests,
