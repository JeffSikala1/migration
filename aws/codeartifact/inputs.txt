For future uploads, if you need to manually publish an artifact like this, it’s better to use mvn deploy:deploy-file instead of a direct REST upload.

That ensures the POM and metadata are generated correctly and avoids resolution issues like the one we hit.


mvn deploy:deploy-file \
  -DgroupId=gov.gsa.cnxs.db \
  -DartifactId=pg-datafile \
  -Dversion=02.00.000.50 \
  -Dpackaging=tar.gz \
  -Dclassifier=postgres-data \
  -Dfile=pg-datafile-02.00.000.50-postgres-data.tar.gz \
  -DrepositoryId=conexus-release-local \
  -Durl=https://artifactory.mgmt.cnxs.vpcaas.fcs.gsa.gov/artifactory/conexus-release-local



This will automatically generate and publish the corresponding POM alongside the artifact, which Maven requires for dependency resolution.
