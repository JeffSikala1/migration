

Item 3 – Token Expiration Policy (Completed)

Issue/Question:

Artifactory access tokens previously had expiration periods up to one year. Security requested reducing token lifetimes to 90 days.

Notes:

Completed. Global token expiration policy was updated to 90 days. Notifications were provided to impacted users prior to token expiration to allow rotation of existing credentials.

Item 4 – Move Docker Data to EFS

Issue/Question:

Docker application data is currently stored under /var/lib/docker on the same volume as the operating system. This created storage concerns during the recent application upgrade and needs to be relocated.

Notes:

Planned enhancement. Docker data will be migrated from /var/lib/docker to an EFS-backed mount under /app to separate application storage from the OS volume and provide additional capacity for future growth.
