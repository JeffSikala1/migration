I traced the DISC behavior and found that the deploy script there pointed at the conexus-plugin-repository virtual repo, which let Artifactory's routing handle where artifacts actually landed. Sometime during migration, the script was changed to point directly at conexus-snapshot-local, which broke release branch builds because they publish -RC artifacts that can't go in a snapshot-only repo.
I updated the shared deploy script in bamboo-deployment to point back at conexus-plugin-repository to match DISC and let the virtual repo do the routing. Tested on Billing SFTP develop build ran clean, artifacts deployed correctly, and latestVersion populated for downstream Deploy plans. Since this is a shared script change, the same fix applies to all 8 affected plans, so release branch publishing should be working across the board now.
