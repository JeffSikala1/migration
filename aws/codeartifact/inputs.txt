The AWS WAFv2 Web ACL is attached directly to the Conexus ALB (regional scope) with a default-allow action, so only traffic matching a rule is blocked. Rules are evaluated in priority order and include rate-based statements (general traffic and SOAP/JSON API traffic), byte-match statements for oversized headers/body, a byte-match BadBot User-Agent filter, and AWS-managed XSS and SQLi match statements. A custom 429 response body is returned for rate-limit blocks. Visibility is enabled per-rule via CloudWatch metrics and sampled requests.
