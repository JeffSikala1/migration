✅ Final-State Signals (Authoritative)

Release is complete if ALL are true:
	•	release tag exists
	•	full expected artifacts exist in conexus-release-local
	•	release branch is absent OR safe to remove

👉 If true:
	•	skip promote
	•	skip finalize
	•	skip cleanup
	•	do not fail the plan

⸻

📦 Artifact Validation (Critical)

Always validate full expected artifact set, not partial.

States:

Condition	Action
0 artifacts	proceed with promotion
FULL set exists	skip promotion
PARTIAL set exists	❌ FAIL (inconsistent release)

Never treat “some artifacts exist” as success.

⸻

🧪 Git Finalization Rules

Must:
	•	validate release branch exists before merge
	•	validate integration branch exists
	•	check if tag exists
	•	verify tag ancestry when possible

Allowed outcomes:
	•	“Already up to date” → OK
	•	“Nothing to commit” → OK

Do NOT:
	•	fail solely on ancestry reproving
	•	assume checkout branch = integration branch

⸻

🧹 Cleanup Rules (Very Important)

Cleanup is best-effort only.

Must:
	•	be idempotent
	•	be rerun-safe
	•	tolerate already-finalized state

Behavior:
	•	If final-state signals exist → skip OR best-effort cleanup
	•	If branch deletion fails → DO NOT fail build
	•	If ancestry cannot be reproven → still allow cleanup

Golden rule:

👉 Cleanup failure ≠ release failure

🧷 Proven Implementation Pattern

Promote Stage
	•	validate SSH key
	•	resolve Maven version
	•	derive release/<version>
	•	validate release branch

If branch missing:
	•	check:
	•	tag exists
	•	FULL artifact set exists
	•	if true → skip release

Then:
	•	convert -RC → -SNAPSHOT on release branch (if needed)
	•	validate release repo:
	•	0 → promote
	•	full → skip
	•	partial → fail
	•	run promote.py per component

⸻

Finalize Stage
	•	resolve version again
	•	validate:
	•	tag
	•	branch
	•	artifacts

If already finalized:

👉 skip everything

Else:
	•	merge release → integration branch
	•	remove -SNAPSHOT
	•	commit if needed
	•	tag if needed
	•	push branch + tag

⸻

Cleanup
	•	if skip flag → exit 0
	•	if finalized:
	•	attempt branch deletion
	•	ignore failure
