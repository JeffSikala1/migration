Restore Database, Repositories and Configuration from a Backup
Show available restore files.
# docker exec -it bitbucket_backup_utils /app/bitbucket-scripts/bitbucket.diy-restore.sh
Usage: /app/bitbucket-scripts/bitbucket.diy-restore.sh <backup-file-name>.tar.gz
Available backups:
bitbucket-20160603-193649-609.tar.gz  bitbucket-20160604-000937-977.tar.gz  bitbucket-20160606-155836-716.tar.gz
Run a restore.
docker exec -it bitbucket_backup_utils /app/bitbucket-scripts/bitbucket.diy-restore.sh bitbucket-20160606-155836-716.tar.gz
You must restart the Bitbucket container after a restore.
docker restart bitbucket_server
Upgrade Procedure
Run a backup
docker exec -it bitbucket_backup_utils /app/bitbucket-scripts/bitbucket.diy-backup.sh
Destroy current Bitbucket, postgres and util containers
docker rm -f -v bitbucket_server postgres_server bitbucket_backup_utils
Run salt
[root@oireasd0111 ~]# salt 'prod.docker-engine.oireasd0120.edc.ds1.usda.gov' state.apply bitbucket
or
[root@oireasd0120 ~]# salt-call state.apply bitbucket
Run a restore of the file created in step 1 (be sure to wait for Bitbucket to start up completely first)
docker exec -it bitbucket_backup_utils /app/bitbucket-scripts/bitbucket.diy-restore.sh bitbucket-20160606-155836-716.tar.gz
Restart Bitibucket container
docker restart bitbucket_server
