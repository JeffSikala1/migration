NAME:
   jf config - Server configuration commands

USAGE:
   jf config command [command options] [arguments...]

COMMANDS:
   add         Adds a server configuration.
   edit        Edits a server configuration.
   export, ex  Creates a server configuration token. The generated Config Token can be imported by the "jf config import <Config Token>" command.
   import, im  Imports a server configuration from a Config Token. A Config Token is generated by the "jf config export <Server ID>" command.
   remove, rm  Removes the stored configuration. In case this argument is followed by a configured server ID, then only this server's configurations is removed.
   show, s     Shows the stored configuration. In case this argument is followed by a configured server ID, then only this server's configurations is shown.
   use         Set the active server by its ID.

OPTIONS:
   --help, -h  show help
